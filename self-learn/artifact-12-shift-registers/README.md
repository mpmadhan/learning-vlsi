# Shift Registers  
## RTL  
1. siso.v : RTL Code that implements Serial IN Serial OUT Shift Register  
2. sipo.v : RTL Code that implemetns Serial IN Parallel OUT Shift Register  
3. pipo.v : RTL Code that implements Parallel IN Parallel OUT Shift Register  
4. piso.v : RTL Code that implements Parallel IN Serial OUT Shift Register
5. lfsr.v : RTL Code that implements Linear Feedback Shift Register  
6. universal_sr.v : RTL Code that implements Universal Shift Register
   
## TB  
1. siso_tb.v : Testbench for Serial IN Serial OUT Shift Register (siso.v)  
2. sipo_tb.v : Testbench for Serial IN Parallel OUT Shift Register (sipo.v)  
3. pipo_tb.v : Testbench for Parallel IN Parallel OUT Shift Register (pipo.v)  
4. piso_tb.v : Testbench for Parallel IN Serial OUT Shift Register (piso.v)  
5. lfsr_tb.v : Testbench for Linear Feedback Shift Register (lfsr.v)
6. universal_sr_tb.v : Testbench for Universal Shift Register (universal_sr.v)
